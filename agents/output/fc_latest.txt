## 📋 【1】FC本部設立の法的要件

### 🔐 中小小売商業振興法（フランチャイズ・チェーン本部準則）

#### 必須情報開示書面（9項目）

```
✓ 本部企業の概要（商号・資本金・主要役員）
✓ フランチャイザーの経歴・経営成績
✓ 加盟金・ロイヤリティの金額・計算方法
✓ 設備費・商品仕入費等の初期投資額
✓ 契約期間・更新・解除条件
✓ 加盟店舗の既存数・営業成績（平均売上・利益率）
✓ 加盟店が負担すべき費用一覧
✓ 本部が提供する支援内容・研修制度
✓ 契約解除に伴う加盟店の対応義務
```

#### 提出義務機関
- **公正取引委員会**（全国）
- **栃木県庁商業・サービス産業課**
- 加盟店契約前に書面交付が法的義務

| 資格 | 取得者 | 期間 | 費用 |

### 💰 B）収支モデルの明確化

#### 現在の財務データの「可視化」が急務

```
【直営2店舗の損益分岐点分析】

1. 大田原店の場合
   ├─ 現月次売上：_____万円
   ├─ 現月次固定費（家賃・人件費）：_____万円
   ├─ 変動費率（サプリ・消耗品）：____%
   └─ 損益分岐点売上：_____万円

2. 那須塩原店の場合
   └─ 同上

【加盟店に提示する参考スペック】
- 初期投資額（内訳）
  ├─ 店舗改装費：150～300万円
  ├─ 機器購入費（サンドバッグ等）：100～200万円
  ├─ 看板・装飾費：50～100万円
  ├─ 初期在庫：30～50万円
  └─ 合計：330～650万円

- 月次収支イメージ
  ├─ 会員月額売上：800万円（会員150名×月会費5,000円）
  ├─ ロイヤリティ（売上10%を想定）：▲80万円
  ├─ 家賃：▲60万円
  ├─ 人件費：▲200万円
  ├─ 光熱費：▲20万円
  └─ 営業利益（見込み）：440万円
```

#### 重要：「平均的な加盟店の損益」も公開義務
- 独立行政法人 中小企業基盤整備機構の**「FC事業の実態調査」**から業界平均を参照
- フィットネス業界平均：月間営業利益率は売上の25～35%程度
