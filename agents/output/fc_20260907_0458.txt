## 🏛️【1】FC本部設立の法的要件

### **①《中小小売商業振興法》情報開示書面**
フランチャイズ契約時に**加盟者に対して必ず開示が必要**です。

**開示義務のある項目：**
```
✓ FC本部の商号・住所・代表者名
✓ 事業内容・経営実績（直営店の3年分財務諸表）
✓ 加盟金・ロイヤリティ等の費用体系
✓ 加盟店舗数・解約店舗数の推移
✓ 契約更新・解除条件
✓ 加盟者負担の初期投資額（詳細内訳）
✓ 研修内容・営業開始までの期間
✓ 紛争解決機関の情報
```

**作成のポイント：**
- 弁護士による**法的チェックが必須**（費用：30～50万円）
- 公正取引委員会の「フランチャイズチェーン契約書標準例」に準拠
- 虚偽記載は**加盟者側の契約解除権**につながる

### **②必須手続き・許認可**

| 手続き | 対応 | 期間 |
|--------|------|------|
| **法人登記** | FC本部が別法人化（推奨） | 1週間 |
| **健康増進施設認定** | 既取得済みなら継承可能 | 確認要 |
| **商標登録** | 「Honey LaRva」をFC対象に拡張 | 6～8ヶ月 |
| **個人情報保護方針策定** | FC加盟店の顧客情報管理ルール | 2週間 |
